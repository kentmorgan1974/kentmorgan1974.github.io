Litwell

Search scientific papers, preprints and patents from one window, and keep every result in a single file.

What it does

Litwell is a desktop program for searching the published literature, preprint servers and patent offices without visiting each one separately. You enter a keyword, author, title, journal or date range, choose a source, and Litwell adds the results to one file on your computer.

Each record is kept with its title, authors, journal, date, DOI and a working link, along with the date and terms of the search that found it. Duplicates are skipped by DOI (or by title when there is none), so you can run many searches over weeks and still end up with a single clean list.

  • Eight sources, chosen from a drop-down list.
  • Results saved as an Excel workbook (with a Search Log sheet of every query), CSV, plain text, Markdown, RIS or BibTeX.
  • Continue an existing file, or start a new dated one at the beginning of a session.
  • A duplicate checker for Excel files that asks before deleting anything and saves a backup first.
  • Crash-safe saving: if a file is open in Excel, or becomes damaged, the previous file is kept and the new results are written to a recovery file.

Setting up patent search

The two patent sources are free, but each patent office asks you to identify yourself with a key. It is a one-time step of a few minutes. The other six sources need nothing.

USPTO (US patents)

  1. Sign in or create an account at data.uspto.gov.
  2. In your account settings, generate or copy your API key.
  3. In Litwell choose File → API Keys & Contact…, paste it into USPTO API key, and save.

EPO (worldwide patents)

  1. Register for free at developers.epo.org.
  2. Sign in and create an app. You receive a Consumer Key and a Consumer Secret.
  3. In Litwell choose File → API Keys & Contact…, paste both into the EPO fields, and save.

The first time you open it

The program is not signed with a paid developer certificate, so your computer asks you to confirm once. After that it opens normally.

Windows

  1. Download the file and open it.
  2. If you see Windows protected your PC, click More info, then Run anyway.

Mac

  1. Download the zip and double-click it to unpack it.
  2. Drag the app to Applications and open it.
  3. If macOS says it cannot check the app, open System Settings → Privacy & Security, scroll down and click Open Anyway. On older versions of macOS, right-click the app and choose Open.

Privacy

Searches go directly from your computer to the public databases. Litwell has no account system, and nothing is sent to us. Your results are saved wherever you choose, and your settings (including any keys you enter) are stored in a small file in your user folder.
